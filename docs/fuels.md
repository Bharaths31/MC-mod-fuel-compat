# Supported Fuels

The mod dynamically adds support for various high-efficiency liquid fuels. Below is a list of the currently supported fuels and their default multipliers.

!!! note "What is a multiplier?"
    The multiplier determines how much fuel value the liquid provides compared to the default base burn time (which is `1200` ticks). A multiplier of `1.0` means one bucket is equivalent to the base burn time. `2.0` means it lasts twice as long.
